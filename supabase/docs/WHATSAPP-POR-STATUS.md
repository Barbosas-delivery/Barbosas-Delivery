# WhatsApp por status

A Fase 41 adiciona mensagens rápidas para a loja enviar ao cliente pelo WhatsApp conforme o andamento do pedido.

## Mensagens disponíveis

- Pedido aprovado
- Saiu para entrega
- Pedido entregue
- Pedido cancelado
- Lembrete de pagamento

## Como configurar

Acesse **Configurações da loja > Mensagens de WhatsApp** e edite os textos.

Variáveis aceitas:

- `{cliente}`
- `{pedido}`
- `{loja}`
- `{total}`
- `{taxa}`
- `{status}`
- `{previsao}`
- `{pagamento}`

## Como usar

No card do pedido, use os botões de mensagens rápidas. O sistema abre o WhatsApp com a mensagem pronta. O envio continua sendo manual pela loja, mantendo a Opção A.
