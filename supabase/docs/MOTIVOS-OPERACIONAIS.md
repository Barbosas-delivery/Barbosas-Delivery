# Motivos operacionais padronizados

A Fase 46 padroniza os motivos usados em cancelamentos e problemas na entrega.

## Cancelamento de pedido ou venda

Motivos disponíveis:

- Cliente desistiu
- Produto indisponível
- Endereço incorreto
- Fora da área de entrega
- Pagamento não aprovado
- Pedido duplicado
- Problema operacional da loja
- Outro motivo

Quando o motivo for **Outro motivo**, os detalhes passam a ser obrigatórios.

## Problema na entrega

Motivos disponíveis para o entregador:

- Cliente não atende
- Endereço errado
- Cliente ausente
- Problema com pagamento
- Moto com problema
- Pedido avariado
- Região insegura
- Outro motivo

O entregador pode digitar o número da opção ou escrever um motivo próprio. Quando escolher **Outro motivo**, o sistema pede uma descrição complementar.

## Objetivo

Esses motivos ajudam a manter o relatório, a auditoria e o histórico dos pedidos mais organizados. Também reduzem mensagens soltas e diferentes para o mesmo problema.
